Getting started

Connect in six steps

  1. Install or update Ultimatum on Android.
  2. When available, download Windows Companion from the verified official release above and install it.
  3. Connect the phone and PC to the same trusted local network (a wired PC and Wi-Fi phone can work on the same LAN).
  4. On Android, find PC Connect, open it, and choose Start to activate PC Bridge. Keep the service running.
  5. On Windows, choose Find phone, enter the Security Token displayed on Android if requested, and approve the computer on your phone.
  6. Use Send to phone or Receive from phone. Follow the progress and completion status.

You do not need Windows Companion for browser-based PC Bridge transfers. Browser mode remains an alternative without installing desktop software.

First connection · Android + Windows

Can't find “PC Bridge” on your phone? Look for “PC Connect”.

In the Android app the connection feature is called PC Connect. PC Bridge is the local transfer service that you start inside that screen. This is different from the QR-based Android-to-Android Send / Receive feature.

1 · On your Android phone

Update Ultimatum from Google Play. Open the app and find PC Connect on the app's main interface (scroll if necessary). Open that screen, then press Start / Start PC Bridge to enable the local service. It should show an address, port or connection link, and a security token.

2 · On Windows

Launch Ultimatum Windows Companion. Connect the PC and phone to the same trusted local network. Choose Find phone. If your phone appears, select it. Otherwise use the manual address / copied-link option and the details displayed on the Android screen.

3 · Approve the computer

In Windows Companion enter the Security Token if requested and choose Connect / Approve on phone. Return to Android and approve the computer in the pending computer / approval prompt. The desktop should then report Connected.

4 · Transfer a small file

Select a small test photo in Windows Companion and use Send to phone, or select a phone file in Receive from phone to save it to Windows. Confirm completion before transferring larger files.

Important: Windows Companion does not yet provide a PC-screen QR pairing code to scan with your phone. QR pairing between Android phones is a different feature. We are evaluating a dedicated PC-to-phone QR connection flow. Until released, use Find phone or the manual connection fallback.

Need a screenshot-based walkthrough? If the PC Connect option is missing, please email support with the Android app version and a screenshot of its main screen. Hide any security token or connection link before sending. We can then point to the exact entry on your installed version.

Privacy, local access and file safety

Current PC Bridge sessions use HTTP, not HTTPS. Data and session tokens are not encrypted on the local network. Use a trusted private LAN, do not expose the PC Bridge port to the public internet, and avoid transferring confidential files over networks you do not control.

PC approval and temporary tokens restrict access but are not substitutes for encrypted transport. Windows Companion can store a local pairing identifier and transfer diagnostics; received files are saved to the destination you choose.

Quick troubleshooting

Windows cannot find the phone

On Android look for PC Connect (the screen name), start PC Bridge inside it, and keep the phone and PC on the same trusted local network. Retry Find phone. If discovery fails, use the full local connection address and token shown on the Android screen.

Connection approved, but no files transfer

Check that both apps are current, PC Bridge is running, and the computer is still approved. Reconnect and retry with a small test file.

A transferred file is missing

Check transfer activity and the corresponding Send or Receive list. On Android, saved files and PC Bridge's private received-file area may be different locations.

Why can't I download the installer?

The download activates only after a public GitHub Release includes the exact installer and GitHub reports its matching SHA-256 digest. Until then, the software is in local testing.

Windows shows an unknown publisher

Early builds are not Authenticode-signed. Do not disable Windows security controls. Verify the official release and its SHA-256 before running an installer.
