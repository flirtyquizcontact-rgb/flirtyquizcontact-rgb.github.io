Easy connection - QR pairing

Connect Windows and Android in four easy steps

You do not need to type an IP address, port or security token when using QR pairing. Use Ultimatum Android 2.0.16 or newer with the QR-enabled Windows Companion. Both devices must be on the same trusted local network.

01▣

Open Companion on Windows

Launch Ultimatum Windows Companion. Select Pair by QR - Easy to display a temporary pairing code on your PC.

02▦

Scan using your phone

In Ultimatum for Android, choose the green WINDOWS PC - CONNECT / SCAN QR action, then SCAN WINDOWS QR - CONNECT. Point the phone at the code on your PC screen.

03✓

Approve on Android

Look near the top of PC Connect for the incoming computer request. Tap the green APPROVE & CONNECT button. Scanning alone never authorizes a PC.

04⇄

Send and receive

After Windows reports Connected, choose Send to phone or Receive from phone. Try a small file first.

Security: The QR code is temporary and expires after approximately 2 minutes. If it expires, generate a new one on Windows. Phone approval is still required. Use only a trusted private network.

If QR is not available

Find phone or connect manually

On Android - PC Connect

Open PC Connect, not the phone-to-phone QR transfer flow. Start the PC Bridge service. If the green QR option is missing, check that the installed Android version is 2.0.16 or newer.

On Windows - Find phone

Choose Find phone and select your Android device on the same local network. If discovery fails, choose the copied-link or manual address option and use the address and security token displayed on Android.

PC connected by Ethernet and phone connected by Wi-Fi can work when they share the same local network. Some guest Wi-Fi networks, client-isolation settings and firewalls prevent device discovery. Mobile hotspots may work when local device-to-device traffic is permitted.

Privacy, local access and file safety

Current PC Bridge sessions use HTTP, not HTTPS. Data and session tokens are not encrypted on the local network. Use a trusted private LAN, do not expose the PC Bridge port to the public internet, and avoid transferring confidential files over networks you do not control.

PC approval and temporary tokens restrict access but are not substitutes for encrypted transport. Windows Companion can store a local pairing identifier and transfer diagnostics; received files are saved to the destination you choose.

Help and troubleshooting

Need help connecting?

I cannot find PC Bridge on Android

Look for PC Connect. In Android 2.0.16 or newer, you can also use the green WINDOWS PC - CONNECT / SCAN QR option from the main interface. PC Bridge is the service inside PC Connect.

The QR scan does not connect

Confirm both devices use the same trusted local network and are running compatible versions. Generate a fresh QR from Pair by QR - Easy if the old code has expired. Keep the Windows app open until you have approved the request on Android.

Where do I press Approve?

After scanning, open the Android PC Connect screen and look near the top for the pending computer request. Select the green APPROVE & CONNECT button or Deny. The PC remains unauthorized until you approve it.

Windows cannot discover the phone

Use Find phone or the copied-link/manual address fallback. Check PC firewall, guest-network isolation and whether Android PC Bridge is running. A phone hotspot can work if devices may communicate locally.

Video or document preview will not open

Video and audio depend on Windows codecs. DOCX previews text only. PDF, XLSX and PPTX open through a suitable Windows application after confirmation. Preview size limits apply. Use Save selected when preview is not supported.

Windows shows an unknown publisher

The current Windows installer is not Authenticode-signed. Verify that you downloaded it from our official GitHub Release and compare its SHA-256. Do not disable security protections for unknown or untrusted software.

Why is the legacy installer shown?

If the latest release is not yet verified on GitHub, the page may offer the older v1.0.0 installer explicitly labelled Legacy. That release does not include the new Windows QR pairing and rich preview. Return once the latest verified release is available.
