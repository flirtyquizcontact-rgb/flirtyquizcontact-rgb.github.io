Setup in five steps

  1. Install Ultimatum on your Android phone from Google Play.
  2. Once a public installer is available, install Windows Companion from the official release.
  3. Connect both devices to the same trusted Wi-Fi network and open PC Bridge → Start on Android.
  4. In Windows Companion select Find phone, enter the temporary security token shown on Android, and approve the PC on the phone.
  5. Use Send to phone and Receive from phone to transfer your selected files.

Safety & privacy

Current local transfers use HTTP, not HTTPS. Content and session tokens are not encrypted in transit. Use only a trusted private network; do not forward the PC Bridge port to the internet or send confidential files over an untrusted LAN.

File names and transfer metadata are processed to provide the service. The desktop client stores its local pairing identifier and limited diagnostics on Windows; no automatic cloud file upload is required for the local transfer workflow.

Bulk delete and ZIP are Pro features where supported by the Android app. Basic transfers and saving individual files are available without Pro.

Troubleshooting

Phone not found: Start PC Bridge and ensure both devices are on the same local network. Enter the IP shown on Android if discovery is unavailable.

Connected but cannot send: Confirm the PC is approved, keep the Android service running, and reconnect. The app verifies uploaded file contents.

Windows publisher warning: early test builds may be unsigned. Do not disable security protections to run an unknown installer. Check the SHA-256 published with any official release.
