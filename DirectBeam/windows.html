Connect your phone to Windows.

A dedicated desktop app for secure transfers. Pair once, then send and receive files with clear controls.

Download for Windows — coming after QA

1. Prepare Android

  1. Open DirectBeam on your phone.
  2. Choose PC Connect → Windows Companion.
  3. Start the PC session. Keep the phone and computer on the same local network.

2. Install & pair

  1. When the verified installer is available, download it here on your Windows PC.
  2. Open DirectBeam Companion and select your phone.
  3. Compare the short security code displayed in both apps.
  4. On Android, tap PAIR WINDOWS PC and enter the eight-digit code on Windows.

3. Transfer your files

Windows → Android: use SEND FILES or drag files into the desktop workspace. Check files in the Android PC workspace.

Android → Windows: choose PHONE LIBRARY (Photos, Videos, Documents, Downloads, etc.), select a file, then SAVE SELECTED TO PC. The default folder is Downloads\DirectBeam; you can choose another location.

Use OPEN RECEIVED FOLDER to locate your downloaded files.

Need a connection without installing Windows software?

Use DirectBeam's PC Connect Browser mode. On your phone, open PC Connect → Show browser link / QR and open the generated HTTP link in Edge or Chrome on a trusted home or office LAN.

Never share a session token or pairing code publicly.
