Quick start

Connect in six simple steps

For first-time users. Pairing does not start the five-minute Pro demonstration.

1

Install Android app

Install or update DirectBeam on Google Play, then open it on your Android phone.

2

Start the phone session

Open PC Connect on Android. Check that the PC/API session shows Live / Running. If it is stopped, tap the available Start control and leave the session active during transfers.

3

Use the same local network

Connect your phone and Windows PC to the same trusted home or office network. If Windows requests a network permission, allow the app on private networks only.

4

Launch Windows Companion

Open DirectBeam Companion on Windows and use its Find / Scan phone option. If your phone is already paired, try the saved-device reconnect option.

5

Approve secure pairing

For a new PC, check the verification information displayed by both devices. Approve the connection on Android and enter the 8-digit pairing code as requested. Never share the code or session token.

6

Transfer your files

Use PC Workspace to send files to Android. Open Phone Library to select authorized files and Save to PC. Received files are normally saved in Downloads\DirectBeam.

Using browser mode instead? Windows installation is optional for browser transfers. On Android, open PC Connect, start its browser session and use the URL/QR shown by the phone in a browser on the same trusted network.

Privacy and file safety on Windows

Pairing information is stored locally on your PC, including a phone identifier and TLS fingerprint; the pairing credential is stored in Windows Credential Manager. Transfer files are saved in the folder you select. Uninstalling Windows Companion may not remove those downloaded files or paired-device records. Visit the DirectBeam Privacy Policy, Terms of Service and Data Deletion & Local Data Controls for more details.

Windows Companion uses authenticated HTTPS for supported paired-device connections. The alternative browser-transfer mode uses local HTTP; only use that mode on trusted private networks. Never share pairing codes, tokens or local connection addresses publicly.

Troubleshooting

If your phone does not connect

Windows cannot find my Android phone

Confirm the Android PC Connect session is started and both devices are on the same trusted LAN. Keep the phone app active for the first pairing. Some routers or firewalls block local discovery; use the app's manual connection flow if available and compare the certificate before approving.

It says disconnected or the pairing code does not work

Restart the PC session on Android, reconnect from Windows and follow the pairing prompt shown in both apps. The eight-digit pairing code is only for pairing; do not paste private browser session links into public messages.

Photos, videos or documents are missing from Phone Library

Android restricts access to personal storage. Grant the relevant media permission when requested, or choose files through the Android picker. For Advanced Folders, first add a specific authorized folder on the phone. The Windows app cannot automatically read all private folders.

When does my Pro preview start and end?

The one-time five-minute preview begins only when you confirm its activation after connecting the phone. It allows new Pro actions during the remaining time. A transfer already underway can finish after the timer ends; Free transfers remain available.

Where are downloads saved?

Windows downloads are normally placed under your Downloads\DirectBeam folder, unless you choose a different destination in the Companion.

Windows warns about an unknown publisher or SmartScreen. What should I do?

Some Windows releases may not have an Authenticode code-signing certificate and can trigger a Windows security prompt. Download only from this official page or the linked GitHub repository, and compare the installer SHA-256 with the value in the release notes before proceeding. Do not disable Windows Defender or SmartScreen system-wide. If you cannot verify the installer, do not run it.

Why is the installer button unavailable?

Only public releases with the verified Windows installer asset name are offered here. If no release is published or the GitHub release service cannot be checked, the page does not offer an unverified executable. Check the official GitHub releases link above.
